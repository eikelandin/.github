# .github

The default security policy, code of conduct, contributing guide and issue forms for every public repository of [@eikelandin](https://github.com/eikelandin). GitHub shows these files in any of those repositories that has no file of the same kind ([default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).
